# AEP / QMAEP Toolkit

用于处理用户自有的 QQ 音乐银河音效工程文件：检查和调整 AEP 参数、在 AEP
与 QMAEP 间转换、打包 AEPK，以及生成自定义音效分享二维码。

本工具包基于对 QQ 音乐自定义音效工程文件和可正常载入的分享二维码进行的格式
兼容性分析。重点是让用户自有工程在分享和导入场景中保持正确的字段布局与数据
一致性。

## 支持的工作流

- 查看或修改 AEP 中已识别的参数。
- 使用用户提供的 key 在 AEP 与 QMAEP 之间转换。
- 打包或解包 AEPK。
- 生成并验证 QQ 音乐自定义音效分享二维码。

完整的操作说明见 [SKILL.md](SKILL.md)。

## 自定义音效二维码

生成二维码前，先将 QMAEP 转为 AEP。分享参数和验证方法见
[docs/share_qrcode_protocol.md](docs/share_qrcode_protocol.md)。该文档记录了从可正常
载入的样本中确认的 URL 字段布局、数据封装方式和本机 UIN 的最小化读取规则。

二维码载荷只包含 AEP、音效名称和 UIN。读取本机 UIN 必须取得用户明确授权；
工具不会读取、输出或保存 Cookie、会话令牌、密码或其他登录凭据。

## 边界

- 仅处理用户有权使用的工程文件。
- 不包含密钥；转换时由用户显式提供。
- 不下载、导出或处理官方预设和会员资源。
- 公开仓库中的内容可查看和下载；仓库维护者应仅向受信任账号授予写入权限。
